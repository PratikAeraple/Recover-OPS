ARCHITECTURE / 01

Independent copies.
Verified restores.

This is a reference architecture requiring a dedicated virtualization host and separate recovery storage. No BruteHost production disks or services are part of its lab.

Data protection layers

  • Separate workload, backup and restore network boundaries.
  • Snapshots support operational rollback but do not replace an independent copy.
  • Encrypted, versioned copies should use separate credentials and restricted deletion rights.
  • Periodic recovery should run against an isolated destination and verify both data integrity and application behavior.

RPO and RTO method

Recovery Point Objective

Calculate the actual recovery point gap from incident cut-off to the last independently verified copy. Configured backup frequency alone does not prove an achieved RPO.

Recovery Time Objective

Measure from declared service impact until restoration has passed integrity/application checks and the service owner accepts it. Include detection, decision and validation time. This project claims no business target or production recovery timing.
